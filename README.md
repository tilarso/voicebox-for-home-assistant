# Home Assistant Voicebox Integration

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-orange.svg)](https://hacs.xyz/)

[![Add to Home Assistant](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=tilarso&repository=voicebox-for-home-assistant&category=integration)

This integration adds:
- a `voicebox.synthesize` service for text-to-speech requests
- a native Home Assistant TTS provider (`tts.voicebox_*`) available in `tts.speak`
- one config flow per Voicebox server
- one status sensor per configured server
- one enabled/disabled switch per configured server

## What this project is (and is not)

This repository contains a Home Assistant integration (`custom_components/voicebox`) that talks to an existing Voicebox API endpoint.

It does not install Voicebox itself. You must run Voicebox separately, then point Home Assistant to that server.

## Prerequisites

- Home Assistant with HACS installed
- A reachable Voicebox API server
- Voicebox host and port
- Optional API key if your Voicebox deployment requires auth

Notes:
- The integration validates the configured host to reduce unsafe targets (for example loopback/link-local style targets are rejected in config flow validation).
- Default Voicebox port in this integration is `8000`.

## Installation

### Option A: HACS (recommended)

1. Open HACS -> Integrations.
2. Open the menu (3 dots) -> Custom repositories.
3. Add repository URL:
   - `https://github.com/tilarso/voicebox-for-home-assistant`
   - Category: `Integration`
4. Search for `Voicebox` in HACS and install it.
5. Restart Home Assistant.

You can also use the "Add to Home Assistant" button above to add the custom repository.

### Option B: Manual install

1. Copy `custom_components/voicebox` into your Home Assistant `custom_components` directory.
2. Restart Home Assistant.

## Configuration

1. Go to Settings -> Devices & Services.
2. Click Add Integration.
3. Search for `Voicebox`.
4. Enter:
   - `host`
   - `port`
   - optional `api_key`
   - `use_ssl` (Use HTTPS)
5. Submit.

You can add multiple Voicebox servers. Each one becomes a separate config entry and device.

## Entities

Per configured Voicebox entry, the integration creates:

- Sensor: `status`
  - icon: `mdi:state-machine`
  - state from `GET /api/status` (`unknown` fallback when not present)

- Switch: `enabled`
  - icon: `mdi:toggle-switch`
  - toggles Voicebox via API (`/api/enable` and `/api/disable`)

Entity IDs are generated by Home Assistant from your instance/device naming and may vary.

## Services

### Native TTS provider (`tts.speak`)

After setup, Voicebox also registers a native TTS provider entity (`tts.voicebox_*`) that appears in Home Assistant's `tts.speak` action.

Example:

```yaml
action: tts.speak
target:
  entity_id: tts.voicebox_tts
data:
  media_player_entity_id: media_player.living_room_speaker
  message: "Voicebox native TTS is ready"
  options:
    voice: alloy
```

### `voicebox.synthesize`

Send text to Voicebox for speech synthesis.

Service data fields:

- `text` (required): text content to synthesize (non-empty)
- `voice` (optional): voice identifier
- `output_path` (optional): absolute path constrained to `/config/media/voicebox`
- `entry_id` (optional): target Voicebox config entry ID; required when multiple Voicebox entries are configured

Examples:

```yaml
service: voicebox.synthesize
data:
  text: "Hello from Home Assistant"
```

```yaml
service: voicebox.synthesize
data:
  text: "Kitchen reminder"
  voice: "alloy"
  output_path: "/config/media/voicebox/kitchen-reminder.wav"
```

```yaml
service: voicebox.synthesize
data:
  entry_id: "YOUR_ENTRY_ID"
  text: "Route this to a specific Voicebox server"
```

## Security

### SSL / HTTPS behavior (`use_ssl`)

**Important:** `use_ssl` defaults to `false` (`DEFAULT_USE_SSL = False`), so new configurations use plain HTTP unless you explicitly enable HTTPS during setup.

**Risk of default HTTP:**
- Traffic, including any `api_key`, is sent unencrypted.
- On untrusted networks (e.g., public Wi-Fi, some corporate networks), this can expose sensitive synthesized text or API credentials.

**Recommendations:**
- **Enable `use_ssl`** if your Voicebox server supports HTTPS, especially if traffic leaves your local machine.
- If using HTTP, ensure both Home Assistant and the Voicebox server are on a trusted, isolated network segment.
- Treat `api_key` values as secrets. Rotate them if you suspect they have been exposed.

### Output path safety

`voicebox.synthesize` enforces that any `output_path` must be inside the `/config/media/voicebox` directory. The integration rejects directory traversal patterns (`..`), non-absolute paths, and null bytes to prevent writing files to unintended locations.

## Troubleshooting

### Integration setup fails with `cannot_connect`

- Confirm Voicebox is running.
- Confirm Home Assistant can reach `host:port`.
- Check firewall/routing between Home Assistant and Voicebox.
- If Voicebox is HTTPS-only, ensure `use_ssl` is enabled.

### Integration setup fails with `invalid_auth`

- The server was reached but rejected credentials (`401/403`).
- Re-check the configured `api_key`.
- Verify the token format expected by your Voicebox deployment.

### Setup fails with `invalid_response`

- The server was reachable, but returned an API shape this integration could not use.
- Common cause: pointing to a Voicebox web UI route/proxy instead of the API server.
- The integration now probes legacy and newer status endpoints (`/api/status`, `/health`, `/models/status`).
- Verify the target returns JSON for one of those endpoints and not HTML.

### Service error when multiple instances are configured

If you have more than one Voicebox config entry, you must include the correct `entry_id` in all `voicebox.synthesize` service calls to target the correct instance.

### `output_path` validation errors

Make sure `output_path`:
- is absolute (starts with `/`)
- is inside `/config/media/voicebox`
- does not include `..`

### Auth errors (401/403)

- Re-check the configured `api_key`.
- Verify the token format expected by your Voicebox server.
